This package is the approved design and product context for the Volvo Trucks customer-facing B2B portal demo.

## Start here

1. Read `CODEX_HANDOFF.md`.
2. Inspect all five images in `assets/screens/` at full size.
3. Read `docs/functional-scope-source.md` before changing product behavior.
4. Use `docs/screen-specifications.md`, `docs/roles-and-permissions.md`, and `docs/implementation-guidelines.md` as implementation constraints.
5. Use `tokens/design-tokens.json` as a draft visual baseline. Derive exact measurements from the images where they differ.

## Status

The visual direction and buyer persona are approved. The design system is not yet frozen. Treat this package as the source for the next design-system and implementation phase, not as proof that every displayed action has a live API.
